About DTC Code P1358

P1358 is an OBD-II Diagnostic Trouble Code (DTC) in the Powertrain category, specific to VOLKSWAGEN vehicles.

This code indicates: Cylinder 2 Ignition Circuit Open.

If you see this code on your OBD-II scanner, we recommend consulting a qualified mechanic for proper diagnosis and repair.
