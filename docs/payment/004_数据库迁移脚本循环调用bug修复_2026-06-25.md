# 数据库迁移脚本循环调用 Bug 修复记录

> 日期：2026-06-25
> 项目：templates/cf-shop
> 影响范围：scripts/migrate.mjs

---

## 一、背景

`templates/cf-shop/scripts/migrate.mjs` 在 apply 阶段存在循环调用自身的问题。

## 二、根因

`executeStatements()` 函数在处理某些 SQL 语句时，错误地再次调用了 `migrate()`，导致：
1. 无限递归
2. 重复执行迁移
3. 某些情况下卡死进程

## 三、修复内容

1. **移除循环引用**：`executeStatements()` 不再调用 `migrate()`
2. **保留 SQL 注释清理**：继续支持 `-- comment` 开头的注释行
3. **增强重试逻辑**：对 Turso 502/503/504 错误增加 3 次重试（2s/4s/6s 递增延迟）
4. **失败时输出原始 SQL**：便于定位问题
