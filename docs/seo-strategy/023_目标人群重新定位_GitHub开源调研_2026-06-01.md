## 二、目标用户的 SEO 痛点（真实场景）

### 痛点 1：不会做 SEO，但知道需要做

> "我朋友说独立站要做 SEO，但我连关键词是什么都不知道"

- 90% 的跨境卖家 SEO 知识为零
- 看不懂 Semrush/Ahrefs 的英文界面
- 不需要"关键词研究"，需要的是"我的产品页该写什么标题"

### 痛点 2：Shopify 模板默认 SEO 很差

> "我用 Shopify 开了店，但 Google 搜不到我的产品"

- Shopify 默认生成重复 URL（/collections、/products 同时存在）
- 产品描述直接复制供应商文案（大量重复内容）
- 图片没有 alt 标签
- Meta description 自动截断，没有意义

### 痛点 3：竞品在偷流量

> "为什么搜 'wireless earbuds' 搜不到我的店？"

- 不知道竞品用什么关键词
- 不知道自己的排名变化
- 不知道哪些页面出了问题

### 痛点 4：付费工具太贵且是英文

| 工具 | 月费 | 对跨境卖家的问题 |
|------|------|------------------|
| Semrush Pro | $139/月 | 全英文，功能太多用不上 |
| Ahrefs Standard | $99/月 | 全英文，学习成本高 |
| Plug in SEO（Shopify App） | $10-50/月 | 只能审计，不能持续监控 |
| SEO Manager（Shopify App） | $9-59/月 | 功能有限，无竞品分析 |

**结论：跨境卖家需要一个中文界面、价格亲民（$9-29/月）、傻瓜式操作的 SEO 监控工具。**

## 三、GitHub 开源项目深度调研

### 3.1 OpenSEO（every-app/open-seo）⭐ 最重要发现

| 维度 | 详情 |
|------|------|
| GitHub Stars | **756**（增长中） |
| 技术栈 | **Cloudflare Workers + D1 + Drizzle ORM**（与我们的技术栈完全一致！） |
| 定位 | Semrush/Ahrefs 的开源替代品 |
| 核心功能 | 关键词研究、排名追踪、域名分析、反向链接、站点审计 |
| 数据源 | **DataForSEO API**（按量付费，每次查询 ~$0.035） |
| 部署方式 | Cloudflare Workers 或 Docker |
| 商业模式 | 开源免费 + 托管版（beta） |
| 语言 | **全英文** |
| 许可证 | MIT |

**关键发现：**
- OpenSEO 的技术架构（Cloudflare Workers + D1）与我们完全一致
- 但它面向的是**懂 SEO 的英语用户**，功能复杂（关键词研究、反向链接分析）
- **没有中文界面**，**没有跨境电商场景**
- 使用 DataForSEO API，有持续成本

**我们的机会：** OpenSEO 证明了"Cloudflare Workers 上做 SEO 工具"是可行的技术路线。但它的目标用户和我们完全不同。

### 3.2 SEOnaut（sixtynine-company/seonaut-sixtynine）

| 维度 | 详情 |
|------|------|
| GitHub Stars | ~300 |
| 技术栈 | **Go + HTML/CSS**（非 JS 栈） |
| 定位 | 开源 SEO 审计工具 |
| 核心功能 | 站点爬取、问题检测（按严重程度分类） |
| 部署方式 | 自托管（Go 二进制） |
| 在线版 | seonaut.org（免费，限制 500 URL） |
| 许可证 | MIT |

**评估：** 技术栈不同（Go），功能单一（仅审计），不适合直接复用。

### 3.3 其他值得关注的开源项目

| 项目 | Stars | 技术栈 | 与我们相关度 |
|------|-------|--------|-------------|
| SerpBear | ~200 | Node.js | 排名追踪，但需自建代理 |
| SEO Tools（Halo 插件） | - | Java | WordPress 生态，不相关 |
| Awesome SEO Backlinks | - | 资源列表 | 不是工具，是链接列表 |

### 3.4 开源项目总结

```
结论：GitHub 上没有可以直接复用的"跨境电商 SEO 工具"

原因：
1. 现有开源 SEO 工具面向全球英语用户，功能通用
2. 没有项目专门针对"中国跨境卖家"这个场景
3. 没有项目提供中文界面 + Shopify 场景化建议
4. OpenSEO 证明了技术路线可行，但目标用户不同
```

## 六、为什么不自己造轮子，而是站在巨人肩膀上？

### 6.1 可以复用的开源代码

| 来源 | 可复用内容 | 许可证 |
|------|-----------|--------|
| OpenSEO | SEO 检查逻辑、评分算法、D1 查询模式 | MIT ✅ |
| SEOnaut | 审计项分类（critical/high/low）| MIT ✅ |
| 现有 cf-guardian | 整个 Cloudflare 项目骨架 | 自有 |

### 6.2 不建议直接 Fork OpenSEO 的原因

1. OpenSEO 依赖 DataForSEO API（有持续成本，且面向专业 SEO）
2. OpenSEO 的功能（关键词研究、反向链接）对跨境卖家过于复杂
3. OpenSEO 的架构是为"替代 Semrush"设计的，我们需要的是"简化版 SEO 监控"
4. **更好的策略：参考其技术思路，但自己做轻量级版本**

### 6.3 建议的技术策略

```
1. 保留 cf-guardian 的项目骨架（Workers + D1 + Hono + Queue）
2. 参考 OpenSEO 的 SEO 检查项设计（MIT 许可，可参考思路）
3. 参考 SEOnaut 的问题分类方法（critical/high/low）
4. 自己做：
   - 中文界面
   - 跨境电商场景化的检查逻辑
   - Shopify 特定优化建议
   - 白话文告警内容
5. 数据源：自己抓取目标网站 HTML 分析（零成本）
   - 不需要 DataForSEO API
   - 不需要第三方排名数据
   - 先用免费 Google API（Search Console 数据用户自己导入）
```

## 七、快速变现路径

### Phase 0：验证需求（第 1-2 周）

```
动作：
1. 在跨境电商社群（知识星球、微信群、知乎）发帖
   "我做了一个中文 SEO 监控工具，专门帮独立站卖家检查 Google SEO 问题，免费试用"
2. 找 10-20 个跨境卖家免费试用
3. 收集反馈：他们最关心什么？愿意付多少钱？

成本：0 元
目标：确认 10 个以上用户愿意付费
```

### Phase 1：MVP 上线（第 3-4 周）

```
基于 cf-guardian 调整：
1. 界面中文化（dashboard.html、signup.html）
2. 扫描逻辑增加 Shopify 场景
3. 告警内容改为白话中文
4. 接入微信支付/支付宝（或先用 Stripe 支持国际卡）

上线渠道：
- 跨境电商社群推广
- 知乎/小红书发教程（"独立站 SEO 自查"）
- Shopify 社区中文板块
```

### Phase 2：付费转化（第 5-8 周）

```
1. 免费用户限 1 站 + 每周 1 次
2. 付费解锁：每日扫描 + 竞品监控 + 无限站点
3. 目标：100 个付费用户 × ¥29/月 = ¥2,900/月
4. 持续优化：根据用户反馈增加功能
```

### Phase 3：规模增长（第 3-6 个月）

```
1. 内容营销：小红书/知乎/B站持续输出"独立站 SEO"内容
2. 社群运营：建立"跨境 SEO 互助群"
3. 合作伙伴：与 Shopify 代运营公司合作
4. 目标：500 个付费用户 × ¥50/月（均价）= ¥25,000/月
```

## 九、总结

| 问题 | 答案 |
|------|------|
| 服务全球用户还是特定人群？ | **特定人群：中国跨境电商卖家** |

> **不要做"另一个 SEO 工具"，要做"跨境卖家的第一个中文 SEO 助手"。**
