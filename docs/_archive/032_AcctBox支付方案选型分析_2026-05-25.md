## 2. 方案一（推荐）：PayJS

官网：https://payjs.cn

### 2.1 是什么

PayJS 是**微信支付官方服务商**，个人开发者提交资料后，由 PayJS 在微信支付体系内为其开通**官方子商户号**。

**核心技术原理：**
```
用户微信扫码付款 → 钱到你的微信支付商户号
                         ↓
              微信支付 T+1 结算到你的个人银行卡
                         ↓
              PayJS 只作为技术服务方（收手续费）
              ❌ 不经手你的资金（关键区别）
```

### 2.2 申请条件

| 条件 | 说明 |
|------|------|
| **身份** | 身份证（年满18周岁） |
| **银行卡** | 个人储蓄卡（用于微信官方结算） |
| **微信实名** | 微信实名认证的微信号 |
| **网站** | 有付款回调 URL（HTTPS）即可，无需 ICP 备案 |
| **开通费** | **0 元** |

### 2.3 费用结构

| 项目 | 金额 | 收款方 |
|------|------|--------|
| 开通费 | **免费** | — |
| 微信支付官方手续费 | 0.6% | 微信支付 |
| PayJS 服务费 | 0 元（无额外收费） | PayJS |
| **用户实际支付总费率** | **0.6%** | — |

> 例：商品 100 元，你实际到账 99.4 元。

对比同行：虎皮椒 1.38%、易支付 2%-3.5%、YunGouOS 1.38%-1.6%。**PayJS 是同类中费率最低的。**

### 2.4 支持的支付场景

| 场景 | 支持 |
|------|------|
| PC 扫码支付 | ✅ |
| 手机 H5 唤醒微信支付 | ✅ |
| JSAPI（公众号内支付） | ✅ |
| 小程序支付 | ✅ |
| 支付宝 | ❌（PayJS 2021 年起已停止支付宝业务） |

### 2.5 接入步骤（Workers 版）

**仅需新增一个文件 `src/routes/pay.ts`：**

```typescript
// ① 用户下单 → 获取支付二维码
app.post("/api/pay/order", async (c) => {
  const { productId, couponCode } = await c.req.json();
  // ... 创建订单、计算金额 ...
  
  const resp = await fetch("https://payjs.cn/api/native", {
    method: "POST",
    headers: { "Content-Type": "application/x-www-form-urlencoded" },
    body: new URLSearchParams({
      mchid: c.env.PAYJS_MCHID,
      total_fee: String(amountCents),  // 单位：分
      out_trade_no: orderNo,
      notify_url: `${c.env.ORIGIN}/api/pay/callback`,
      sign: generateSign({...}, c.env.PAYJS_KEY),
    }),
  });
  return ok(c, { qrcode: (await resp.json()).qrcode, orderNo });
});

// ② 支付回调（关键）
app.post("/api/pay/callback", async (c) => {
  const body = await c.req.parseBody();
  // 验证签名
  if (!verifyPayJSSign(body, c.env.PAYJS_KEY)) {
    return c.text("sign fail", 403);
  }
  // 调用现有发卡逻辑
  await markPaidAndIssue(c.env.DB, orderId);
  return c.text("success");  // 必须返回 success，否则 PayJS 会重试
});
```

### 2.6 优点

1. **费率最低**（0.6%），与官方微信支付同费率
2. **资金安全**——微信官方直接结算到你的银行卡，PayJS 不经手资金
3. **开通免费**，无一次性费用
4. **运营时间长**（2018 年至今），行业最稳定的个人支付平台之一
5. **API 极简**——签名验证 + 2 个接口，纯 REST，Workers 上直接 `fetch`
6. **文档完善**，SDK 覆盖 Java/PHP/Python/Go

### 2.7 缺点

1. **仅支持微信支付**——覆盖约 85% 用户，缺少支付宝用户
2. **微信风控风险**——这是所有微信支付服务商的通病，非 PayJS 独有
3. **需自行处理投诉工单**——微信支付要求商户在 4 小时内响应投诉
4. **单笔限额**——通常 5 万元以下（对你目前的商品定价影响不大）

### 2.8 风控风险说明

PayJS 本身不风控你，风控来自**微信支付官方**。哪些业务容易被风控：
- 虚拟商品（数字卡密）——**你的场景就是这类，需要注意**
- 高频交易（短时间内大量订单）
- 投诉率高
- 可疑交易模式（整数金额、深夜大量交易）

**降低风控的建议：**
- 金额带角分（如 29.90 而非 30）
- 保持合理交易频次
- 保留完整的发卡记录（你现有的 order_event 日志正好用上）
- 即使处理投诉

## 3. 方案二（备选）：虎皮椒（讯虎支付）

官网：https://www.xunhupay.com

### 3.1 是什么

虎皮椒（XunhuPay）是国内老牌个人支付聚合平台，支持**微信 + 支付宝**双通道。

与 PayJS 的本质区别：
- PayJS：你开的是**微信官方子商户号**，微信直接结算
- 虎皮椒：你开的是**虎皮椒平台的商户号**，资金虽由微信/支付宝官方结算，但虎皮椒平台额外收取技术服务费

### 3.2 申请条件

| 条件 | 说明 |
|------|------|
| **身份** | 身份证 + 支付宝实名 |
| **银行卡** | 个人储蓄卡（微信结算用） |
| **支付宝** | 实名认证的支付宝账号 |
| **开通费** | **118 元**（一次性） |

### 3.3 费用结构

| 项目 | 金额 | 收款方 |
|------|------|--------|
| 开通费 | **118 元** | 虎皮椒平台 |
| 微信官方手续费 | 0.6% | 微信官方 |
| 支付宝官方手续费 | 0.38%~0.6% | 支付宝官方 |
| 虎皮椒平台服务费 | 约 0.78%~1% | 虎皮椒平台 |
| **综合费率** | **约 1.38%（支付宝）/ 1.38%~1.6%（微信）** | 两者合计 |

> 例：商品 100 元，你实际到账约 98.62 元。

### 3.4 支持支付场景

| 场景 | 支持 |
|------|------|
| PC 扫码支付 | ✅ |
| H5 支付 | ✅（微信唤醒 2025.11 后临时关闭）|
| 支付宝 | ✅ |
| 微信 JSAPI | ✅ |
| 小程序 | ❌（已关闭）|

### 3.5 优点

1. **支持多种支付方式**——微信 + 支付宝 + 银联
2. **运营时间长**（2016 年至今，行业最老牌的个人支付服务商）
3. **资金安全**——微信/支付宝官方结算，虎皮椒不经手资金
4. **API 简单**，文档完善
5. **有香港/境外通道**——如果你未来出海，虎皮椒也支持

### 3.6 缺点

1. **费率较高**——综合约 **0.6%（微信/支付宝官方） + 0.78%~1%（平台服务费）**，比 PayJS 贵一倍以上
2. **开通费 118 元**——虽然不多，但属于额外成本
3. **风控更为敏感**——虎皮椒对接的通道较多，受上游通道影响，最近频繁出现微信唤醒支付关闭等问题
4. **夜间结算延迟**——23:00-6:00 到账可能延迟
5. **平台自身也有被微信支付处罚的风险**——如果虎皮椒平台上其他商户的违规行为导致通道被掐，会波及所有商户

### 3.7 风控风险说明

虎皮椒的风控问题比 PayJS 更严重，因为：
- 虎皮椒对接的商户群体更杂（很多灰色产业也在用）
- 上游通道被掐的风险更高
- 2025 年末已经发生过微信唤醒支付被临时关闭的情况

## 4. 方案三（境外备选）：Stripe Global + 香港银行账户

### 4.1 是什么

Stripe 是全球最大的在线支付处理平台之一。中国大陆居民可以通过**申请 Stripe Global 账户（香港区域）** 来接入，收款到香港银行账户。

### 4.2 申请流程

```
大陆护照 → 注册 Stripe Global（选择香港）
                    ↓
          身份验证（护照 + 地址证明）
                    ↓
        绑定香港银行账户用于结算
                    ↓
             开始收款
```

### 4.3 两种香港银行账户方案

| 方案 | 办理时间 | 成本 | 难度 |
|------|---------|------|------|
| **Wise 港币账户** | 1-2 周 | 低（一次性几百元）| ⭐⭐ 中等 |
| **汇丰香港/中银香港实体账户** | 1-4 周（需过港）| 中等（需亲临香港）| ⭐⭐⭐ 较高 |

**Wise 方案（最可行）：**
1. 在 Wise 注册并申请 **港币账户**
2. 获得香港本地银行账号（Wise 提供）
3. 在 Stripe 后台绑定该账号用于收款
4. Stripe 结算到 Wise 港币账户后，可兑换为人民币提现到大陆银行卡

### 4.4 费率结构

| 项目 | 金额 |
|------|------|
| Stripe 交易手续费 | **2.9% + ¥0.24/笔** |
| 货币兑换费（USD→HKD）| 包含在 2.9% 内（Stripe 加收 1% 汇兑费）|
| Wise 提现费（HKD→CNY）| 约 0.41%（按汇率中间价）|
| **综合费率** | **约 4.3% ~ 5%** |

> 例：商品 100 元，各方费用扣完后你实际到账约 **95 元**。

### 4.5 支持支付方式

| 支付方式 | 支持 |
|---------|------|
| Visa/Mastercard | ✅ |
| 银联卡 | ✅（通过 Stripe 香港）|
| 支付宝 | ✅（通过 Stripe 香港）|
| WeChat Pay | ⚠️ 部分区域支持 |
| Apple Pay / Google Pay | ✅ |

### 4.6 优点

1. **全球覆盖**——支持国际信用卡，适合出海或收外币
2. **合规性最强**——Stripe 是全球持牌金融机构
3. **国内用户可用支付宝扫码**——通过 Stripe 香港的 Alipay 通道
4. **技术集成体验好**——文档最完善

### 4.7 缺点

1. **费率太高**（综合 4.3%~5%）——是国内方案（0.6%）的 7-8 倍
2. **申请流程繁琐**——需要香港银行账户
3. **结算周期长**——T+2~T+4
4. **汇率损失**——多一层货币转换就多一层损耗
5. **国内用户付款体验一般**——虽然支持支付宝，但付款页是 Stripe 英文界面
6. ****主要适合面向境外用户的业务**——你的目标用户是国内用户

### 4.8 什么情况下选这个

- 你要**收外币**（美元、欧元等）
- 你的用户有**海外用户**
- 你担心国内支付监管，想要境外支付通道
- 你本身就要办香港银行卡

## 5. 方案四（远期合规）：支付宝当面付

### 5.1 是什么

支付宝官方提供的企业级支付接口，接入的是**支付宝官方通道**，适合有企业资质的商户。

### 5.2 必要条件

| 条件 | 是否必须 | 当前状态 |
|------|---------|---------|
| **营业执照** | ✅ 必须 | ✅ **已有** |
| **对公银行账户** | ✅ 必须 | ❌ **尚未开户** |
| **企业支付宝账号** | ✅ 必须 | ❌ 需开通 |
| **ICP 备案** | ❌ 不需要 | —（支付回调无需备案）|
| **域名 HTTPS** | ✅ 必须 | ✅ Workers 自带 |
| **网站** | ✅ 必须（配置回调地址） | ✅ |

### 5.3 费用

| 项目 | 金额 |
|------|------|
| 开通费 | **免费** |
| 支付宝官方手续费 | **0.6%** |
| 月费 | 无 |

### 5.4 优点

1. **费率最低**（0.6%），与 PayJS 持平
2. **最合规**——支付宝官方直连，资金安全
3. **无需担心跑路**——支付宝不会跑路
4. **风控最宽松**——企业资质 + 对公账户，被风控概率远低于个人方案

### 5.5 缺点

1. **需要有对公账户**——目前最大障碍
2. **需要有企业支付宝**——营业执照办下来后可立即开通
3. **仅支持支付宝**——没有微信支付
4. **对公账户提现到个人账户有税务问题**——对公账户的钱不能随意转入个人账户

### 5.6 什么时候做

**建议作为长期目标**，当前可以两步走：
1. 先用 PayJS 跑起来（今天就能做）
2. 开对公账户 + 企业支付宝 + 当面付接入（1-2 周后升级）

## 6. 最终建议路线图

### 当前阶段（今天就能动手）

```
选择 PayJS
  ├── 0 元开通
  ├── 仅需身份证 + 银行卡
  ├── 0.6% 最低费率
  └── Workers 1 小时对接完成
```

**为什么选 PayJS 而不是虎皮椒：**

| 对比 | PayJS | 虎皮椒 |
|------|-------|--------|
| 费率 | **0.6%** | 1.38% |
| 开通费 | **0 元** | 118 元 |
| 资金 | 微信直接结算 | 微信直接结算（同）|
| 支付宝 | ❌ | ✅ |
| 运营年限 | 6年+ | 8年+ |

差额 0.78% 的服务费，对于发卡项目来说——每 10000 元流水，你就多交 78 元。没有理由为"支持支付宝"这个功能每年多付几千元，因为：

- 你的用户用 PayJS 微信扫码支付覆盖了绝大多数
- 后续升级当面付后，支付宝自然就补上了
- 虎皮椒的支付宝也不是"官方直连"，而是通过聚合通道，体验并无优势

### 中期（1-2 周后）

```
去银行开对公账户 → 开通企业支付宝 → 签约支付宝当面付（0.6%）
                    ↓
          原有 PayJS 保留（用于微信支付）
          新增当面付（用于支付宝）
                    ↓
          双通道并行：PayJS（微信）+ 当面付（支付宝）
```

### 长期（有出海需求时）

```
Stripe Global + Wise 港币账户
  └── 用于接收境外用户付款（美元/欧元/国际卡）
```

### 整体路线图

```
现在                 1-2 周后             有出海需求时
   │                     │                     │
   ▼                     ▼                     ▼
┌────────┐          ┌──────────┐          ┌──────────┐
│ PayJS  │   ═══▶   │ PayJS    │   ═══▶   │ PayJS    │
│ 0.6%   │          │ + 当面付 │          │ + 当面付 │
│ 微信   │          │ 0.6%+0.6%│          │ + Stripe │
└────────┘          │ 微信+支付│          │ 全渠道   │
                     │ 宝双通道 │          └──────────┘
                     └──────────┘
```

### 7.2 完整的支付回调流程（PayJS 示例）

```
用户微信扫码付款
       ↓
微信支付官方处理
       ↓
微信通知 PayJS
       ↓
PayJS 回调 POST /api/pay/callback
       ↓
① 验证签名（防伪造）
② 查询订单状态（防重复回调）
③ 调用 markPaidAndIssue() → 发卡
④ 写入 order_event 日志
⑤ 返回 "success" 给 PayJS
       ↓
用户收到发卡成功通知
```
