常见问题

什么是 URL 编码？

URL 编码（也叫百分号编码）是将特殊字符转换为 %XX 格式的过程。例如空格变为 %20，中文变为 %E4%B8%AD%E6%96%87。

为什么要进行 URL 编码？

URL 中某些字符有特殊含义（如 ? & = #），如果这些字符出现在参数值中，必须编码以避免歧义。

编码和解码有什么区别？

编码是将普通文本转换为 URL 安全格式；解码是将 URL 编码还原为原始文本。
