常见问题

什么是 HTML 转义？

HTML 转义是将特殊字符（如 < > & " '）转换为 HTML 实体（如 < > &）的过程，防止浏览器将其解析为 HTML 标签。

为什么要进行 HTML 转义？

主要是为了防止 XSS（跨站脚本）攻击。如果用户输入的 HTML 代码未经转义直接插入页面，可能执行恶意脚本。

哪些字符需要转义？

必须转义的字符：< 转为 <，> 转为 >，& 转为 &，" 转为 "，' 转为 '。
