# 模板使用说明

## 适用场景

```text
填表
信息收集
邀请申请
活动报名
资料领取
轻量交互
低流量个人项目
```

## 不适用场景

```text
复杂 CRM
多人协作后台
强支付结算
高并发队列
复杂权限系统
```

这些场景可以从本模板演进，但不要一开始塞进模板。

## 核心原则

```text
业务变化只改 src/config/forms.ts。
安全能力默认保留，不要为了省事删除。
验证分只读和写入。
真实 token 不进入 Git。
每次踩坑写 docs。
```

## 业务字段配置

入口：

```text
src/config/forms.ts
```

新增字段只需要加：

```ts
{
  name: "company",
  label: "公司/团队",
  type: "text",
  required: false,
  maxLength: 80
}
```

支持类型：

```text
text
email
textarea
select
```

## 验证闭环

```bash
rtk npm run check
rtk npm run type-check
rtk npm run smoke:readonly
```

只有需要验证写链路时才运行：

```bash
rtk npm run smoke:write
```

## 部署闭环

```text
commit
push
wrangler deploy 或 Cloudflare 自动部署
绑定域名
security_baseline.mjs 合并 WAF
首页 200
/.env 403
/admin challenge
smoke:readonly
```
