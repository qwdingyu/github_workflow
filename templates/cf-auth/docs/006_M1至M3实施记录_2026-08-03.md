## 二、已实测通过的行为

| 场景 | 结果 |
|------|------|
| `GET /api/health` | ok + db |
| 邮箱 sign-up / sign-in / get-session | 200 + session cookie |
| Google social `disableRedirect` | 生成 accounts.google.com URL（假 client） |
| 未登录 `oauth2/authorize` | 302 → `/sign-in?...` |
| `createOAuthClient`（需 session，body 用 `redirect_uris` / `client_name`） | 返回 client_id/secret |
| `adminUpdateOAuthClient({ skip_consent: true })` | 第一方可跳过同意页 |
| 已登录 + skip_consent + PKCE | 302 回 redirect，带 `code` + `iss` |
| `oauth2/token`（Basic client_id:secret + code_verifier） | access_token + id_token |
| `oauth2/userinfo` | sub / email / name |
| `/.well-known/oauth-authorization-server/api/auth` | 200 metadata |

自动化：`npx tsc --noEmit` 0 errors；`npm test` **8/8 passed**。

## 三、实施中踩坑（事实）

### 1. `app.request` 时 `c.env` 可能为 undefined

`Object.assign(c.env, …)` 会 500。改为：

```ts
c.env = { ...(c.env ?? {}), ...options.env }
```

### 2. OAuth well-known 路径

启动 WARN：需存在 `/.well-known/oauth-authorization-server/api/auth`（因 basePath=`/api/auth`）。  
使用官方 `oauthProviderAuthServerMetadata(auth)` 挂载，并 `silenceWarnings.oauthAuthServerConfig`。

### 3. createOAuthClient 字段名

类型要求 **`redirect_uris`（snake）**，不是 `redirectUris`；名称字段为 **`client_name`**。

### 4. skip_consent

创建 body 传入 `skip_consent` 实测未生效；**`adminUpdateOAuthClient`** 可设 `skip_consent: true`。  
第一方 lottery 客户端建议创建后立刻 adminUpdate。

### 5. consent API

需要完整 `oauth_query`（含 `sig`）。同意页把 `location.search` 原样提交；错误签名会 `invalid_signature`。

### 6. D1

本阶段主路径仍为 **libSQL file**；D1 binding 已在 wrangler 声明但**业务未切**（见 docs/005）。

## 四、对 RP（cf-lottery）的接入要点（尚未改 lottery 代码）

```text
authorize:  {base}/api/auth/oauth2/authorize
token:      {base}/api/auth/oauth2/token
userinfo:   {base}/api/auth/oauth2/userinfo
issuer:     {base}/api/auth   （id_token iss 实测如此）
```

- Authorization Code + PKCE（S256）  
- confidential client：`client_secret_basic`  
- 业务映射：`identity_type=auth_user`，`identity_value=iss + ":" + sub`  
- **不要**共享 Better Auth cookie

## 六、与 monorepo 架构钩子

`scripts/validate-architecture.mjs` 默认要求各模板 `schema.ts` 从 `@usethink/cf-core` 导入 5 张公共表。
