## 背景

用户要求：

1. **cf-auth 单独创建 GitHub 仓库**（平台边界、独立发布）  
2. **不仅 Google**，还要 GitHub 等上游社交 IdP  
3. 从**配置文件与全流程**角度做顶层架构，符合最佳实践

本路径 `templates/cf-auth` 已 `git init` 并 `origin` 指向上述仓库，作为**权威工作副本**。
