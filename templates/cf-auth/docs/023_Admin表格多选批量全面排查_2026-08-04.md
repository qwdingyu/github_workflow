# 023 Admin 表格多选 / 批量全面排查

> 日期：2026-08-04  
> 范围：平台 Admin SPA + `/api/admin/*`（对照 docs/020 §6.3，**不臆造后端能力**）  
> 依据：`frontend/src/views/*`、`src/routes/admin.ts`、`src/lib/audit.ts`

## 1. 结论摘要

| 等级 | 项 | 处理 |
|------|----|------|
| **已修** | Blocklist 无多选/批量 | 已有 `batch-remove` + UI（前轮） |
| **已修** | Users 缺「批量下线不封禁」 | 新增 `POST /users/batch-revoke-access` + UI |
| **已修** | 表头半选 / Shift 范围选未接线 | 五表：`indeterminate.prop` + `@click` + `shiftKey` |

| **非缺陷** | Audit 无批量删除 | 设计禁止（`audit.ts` 只追加） |
| **非缺陷** | Dashboard 无多选 | 非数据表 |
| **非缺陷** | 无删除 client / 删用户 / 批量 rotate secret | 020 明确禁止，后端无路由 |

## 2. 后端路由清单（代码事实）

```
GET    /health
GET|POST /clients … batch-disabled | PATCH | rotate-secret
GET|POST /users … block | batch-block | batch-revoke-access
GET|DELETE /users/:id/sessions
DELETE /sessions/:id | POST batch-revoke
GET|POST /blocklist | DELETE :id | POST batch-remove
GET    /audit
```

**不存在：** `DELETE /clients/*`、`DELETE /users/*`、`DELETE /audit/*`、`batch-rotate-secret`、跨页全选 API。

## 3. 前端 × 批量矩阵（修复后）

| 页面 | 多选 | 批量动作 | 后端 |
|------|------|----------|------|
| Clients | ✓ 当前页 | 启用 / 禁用 ≤20 | `batch-disabled` |
| Users | ✓ | 下线不封禁 / 封禁并下线 ≤20 | `batch-revoke-access` / `batch-block` |
| Sessions | ✓ | 下线选中 ≤20；另有按用户「强制全部下线」 | `batch-revoke` / `DELETE …/sessions` |
| Blocklist | ✓ | 批量移除 ≤20 | `batch-remove` |
| Audit | ✓ | **仅**导出本页 / 导出选中 CSV | 无写删 |
| Dashboard | — | 计数卡片 | `GET /health` |

## 4. UX 一致性（本轮）

- 选择范围文案统一「仅当前页」
- 表头 checkbox：`partiallySelected` → `:indeterminate.prop`
- 行 checkbox：`@click` + `shiftKey` 范围选（与 lottery `AdminLogsView` 同模式）
- 搜索/筛选：`setPage(1)` 后再 `reload`（Clients / Users / Blocklist type / Audit）
- 危险操作：`ConfirmDialog` + `mutating`/`batchOperating` 锁

## 5. 明确不做（避免幻觉）

1. 审计批量删除  
2. 批量轮换 secret / 批量改 redirect  
3. 跨页全选 + 一次操作全库  
4. 黑名单「无预览超大导入」（020：导入需预览，未实现则不做）  
5. 把 lottery 租户 Admin 能力照搬到 IdP
