## 八、与 lottery 部署的差异

| 项 | lottery | auth |
|----|---------|------|
| 域名 | lucky.eforge.xyz | auth.eforge.xyz |
| 前端 | 大型 Vue SPA + assets | 极简登录/consent 即可 |
| DB | Turso 业务库 | **独立** auth 库（D1 或另一 Turso DB） |
| Cron | 有 | 通常不需要（可后期 session 清理） |
| R2 | 有 | 无 |

**禁止**把 auth 表塞进 lottery 的 Turso 库。

## 九、回滚

| 场景 | 动作 |
|------|------|
| 错误部署 | `wrangler rollback` 或重新 deploy 上一版本 |
| 域名异常 | 去掉 custom domain / 暂停 worker |
| 数据损坏 | D1/Turso 备份恢复；空库可 migrate 重建（无生产用户时） |
| lottery 受影响 | lottery 未接 auth 前 **零影响**；接入后靠 Logto 回退开关 |
