## 三、生产冒烟（可重复）

```bash
# 默认打 https://auth.eforge.xyz
npm run smoke:prod

# 指定 base / 落盘
PROD_BASE_URL=https://auth.eforge.xyz \
SMOKE_OUT_DIR=/tmp/cf-auth-smoke \
npm run smoke:prod

# 可选：用已注册 OAuth client 验证「未登录 → sign-in 且保留参数」
PROD_OAUTH_CLIENT_ID=<client_id> \
PROD_OAUTH_REDIRECT_URI=https://lucky.eforge.xyz/auth/callback \
npm run smoke:prod
```

脚本驱动**真实 HTTPS** 请求已部署 Worker，检查项：

1. `GET /api/health` ×2  
2. `GET /api/auth-meta/social`  
3. `GET /sign-in`（HTML + 登录线索）  
4. AS / OIDC well-known  
5. `POST /api/auth/sign-in/social`（google、github，`disableRedirect: true`）  
6. `GET /api/auth/oauth2/authorize`（禁止 5xx）  
7. `GET /api/no-such-route-prod-smoke` → controlled 404  

若本地 `.env` 含 `GOOGLE_CLIENT_SECRET` / `GITHUB_CLIENT_SECRET`，脚本会断言响应体**不泄露** secret。

## 四、生产实测摘要（2026-08-03）

### health

- `ok: true`，`db: true`，`service: cf-auth`  
- `baseURL: https://auth.eforge.xyz`  
- `socialProviders: ["google","github"]`

### social

| Provider | IdP host | callback 形态 |
|----------|----------|----------------|
| google | `accounts.google.com` | `…/api/auth/callback/google` under `auth.eforge.xyz` |
| github | `github.com` | `…/api/auth/callback/github` under `auth.eforge.xyz` |

### authorize

| 场景 | 行为 |
|------|------|
| 不存在的 `client_id` | HTTP 200 + JSON `{redirect,url}` → `/api/auth/error?error=invalid_client`（非 5xx） |
| 已注册 smoke client + 合法 `redirect_uri` | → `/sign-in?response_type=…&client_id=…&redirect_uri=…&code_challenge=…`（未登录保留 OAuth 意图） |

> 说明：生产动态 client 注册默认关闭（`/oauth2/register` → 403）。创建 client 使用已登录用户调 `POST /api/auth/oauth2/create-client`。**不要**把 `client_secret` 写入仓库或文档。

### 404

```json
{"error":"not_found"}
```

## 六、运维建议

1. 日常回归：`npm run verify && npm run smoke:prod`  
2. 自定义域 TLS 异常时：先记录 `auth.eforge.xyz` 失败，再对 `cf-auth.mailforwdy.workers.dev` 做**非 social** 面探测；social 仍以自定义域 base 为准  
3. 控制台回调必须精确：  
   - `https://auth.eforge.xyz/api/auth/callback/google`  
   - `https://auth.eforge.xyz/api/auth/callback/github`  
4. 第一方 RP（如 cf-lottery）登记 client：优先 `POST /api/auth/oauth2/create-client`（需登录 cookie）；`scripts/register-oauth-client.mjs` 已对齐该路径。  
5. `skip_consent`：若 HTTP admin-update 404，可用 `node scripts/set-oauth-client-skip-consent.mjs --client-id <id>`（直连 Turso，仅运维）。  
6. lottery 生产接入实施见兄弟仓 docs/067（2026-08-03）。
