## 三、Cloudflare 部署时 secrets

Worker **不能**读本地 `.env`，需：

```bash
cd templates/cf-auth
# 从 .env 取值后 put（交互或管道，勿 echo 进 shell 历史日志）
npx wrangler secret put BETTER_AUTH_SECRET
npx wrangler secret put BETTER_AUTH_URL          # 生产 https://auth.eforge.xyz
npx wrangler secret put DATABASE_URL             # 或 TURSO_URL
npx wrangler secret put TURSO_URL
npx wrangler secret put TURSO_TOKEN
npx wrangler secret put GOOGLE_CLIENT_ID
npx wrangler secret put GOOGLE_CLIENT_SECRET
npx wrangler secret put GITHUB_CLIENT_ID
npx wrangler secret put GITHUB_CLIENT_SECRET
npx wrangler secret put TRUSTED_ORIGINS
npx wrangler secret put ENABLED_SOCIAL_PROVIDERS # google,github
```

生产 `BETTER_AUTH_URL` / 回调须为 `https://auth.eforge.xyz`（与 Google/GitHub 控制台一致）。
