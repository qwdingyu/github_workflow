```text
GET  /api/health              → 200 ok, db=true, socialProviders=["google","github"]

```

---

## 二、部署步骤（已执行）

1. Turso 库 `cf-auth-db` + migrate（docs/010）  
2. `wrangler.jsonc`：`nodejs_compat`、`workers_dev`、自定义域名、vars（无 secret）  
3. **去掉** D1 binding（生产主路径 Turso）  
4. `wrangler secret put`：  
   - `BETTER_AUTH_SECRET`（生产独立随机值）  
   - `DATABASE_URL` / `TURSO_URL` / `TURSO_TOKEN`  
   - `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET`  
   - `GITHUB_CLIENT_ID` / `GITHUB_CLIENT_SECRET`  
5. `npx wrangler deploy`  
6. 自定义域名 SSL 曾短暂握手失败（证书签发中）；约数分钟后 `auth.eforge.xyz` HTTPS 正常
