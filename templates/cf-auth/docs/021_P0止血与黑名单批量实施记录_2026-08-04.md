## 四、行为约定（运维）

1. **「强制全部下线」≠「封禁」**  
   - 下线：清凭证，用户仍可再登录。  
   - 封禁：写黑名单 + 下线；再登录在 **创建 session 前** 失败。

2. **黑名单 ≠ lottery 参与黑名单**  
   - 无 `tenantId`；拦的是 IdP 登录/建 session。

3. **批量只允许启停 client、封禁用户**  
   - **没有**批量轮换 secret、删 client、删用户、删审计。

4. **部署**  
   - 启动/`applyAuthMigrations` 会 `CREATE IF NOT EXISTS auth_blocklist`。  
   - 需重新 `build:frontend` + deploy 后 SPA 才有新菜单。
