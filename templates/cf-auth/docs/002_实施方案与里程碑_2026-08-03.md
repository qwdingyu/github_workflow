### M2 — Better Auth 核心挂载

**动作：**

1. Drizzle schema：`user` / `session` / `account` / `verification`（字段以官方 generate 为准，可参考 lottery smoke 的 camelCase 实践）。  
2. `betterAuth({ baseURL, secret, database: drizzleAdapter(...), trustedOrigins })`。  
3. Hono：

```ts
app.on(["GET", "POST"], "/api/auth/*", (c) => auth.handler(c.req.raw));
```

4. 单测：sign-up / sign-in / get-session（可移植 056 逻辑，独立测试库文件）。  
5. 可选：`sign-in/social` + `disableRedirect: true` 验证 Google URL 生成（假 client id）。  

**验收：** 与 056 同等断言通过；**不**声称 Google 生产可用。  

**依赖安装：** 优先  

```bash
npm install better-auth@1.6.25 --legacy-peer-deps
```

若 peer 冲突，记录到 docs 踩坑。  

---

### M3 — OAuth Provider 本地闭环（关键门禁）

**动作：**

1. 安装 `@better-auth/oauth-provider@1.6.25`。  
2. 启用 `jwt()` + `oauthProvider({ loginPage, consentPage, ... })`（`loginPage`/`consentPage` 为 **必填**，来自包类型定义）。  
3. 迁移 OAuth 相关表：`oauthClient`、`oauthRefreshToken`、`oauthAccessToken`、`oauthConsent`。  
4. 最小 HTML 或简单前端：`/sign-in`、`/consent`（可先服务端渲染极简页，不引入重型前端）。  
5. 脚本注册 **confidential 或 public** 测试 client，redirect 到 `http://localhost:8788/dev/callback`。  
6. 跑通：

```text
/oauth2/authorize
  → 未登录则 /sign-in
  → /consent（若需要）
  → redirect?code=&state=
  → token endpoint
  → id_token / userinfo（按 scope）
```

7. 单测或 `scripts/smoke-oauth.mjs` 固化。  

**验收门禁（未过不进 M4 生产流量）：**

- [ ] code 只能用一次  
- [ ] redirect_uri 不在白名单则失败  
- [ ] PKCE 错误 challenge 失败  
- [ ] client_secret 错误失败（confidential）  
- [ ] `sub` 稳定（同一用户多次授权相同）  

**安全默认：**

```ts
allowDynamicClientRegistration: false
allowUnauthenticatedClientRegistration: false
```

### M4 — Cloudflare 部署

**已核实资源（见 004）：**

- Wrangler 已登录账号 `mailforwdy@gmail.com`  
- D1：`cf-auth`（uuid `f8aa7a07-...`，**0 表**，空库）

**动作：**

2. 绑定 D1 和/或 确认改用 Turso（**D1 适配路径必须先本地 miniflare/wrangler dev 实测**，见 005）。  
3. `wrangler secret put BETTER_AUTH_SECRET` 等。  
4. 迁移远程库。  
5. `wrangler deploy`。  
6. 验证 health +（若已开）well-known。  

**回滚：** 去掉 custom domain / 删 worker 版本；DNS 可先不切若未指向本 worker。

## 六、明确暂停条件

出现以下情况 **停止扩大范围**，先写 docs 再改：

1. OAuth Provider 生产行为与文档不符（token 形态、well-known 路径）。  
2. D1 在 Workers 上 handler 超时或 batch 语义异常。  
3. Google redirect_uri_mismatch 无法用配置解决。  
4. 与 lottery 身份映射出现重复参与漏洞。
