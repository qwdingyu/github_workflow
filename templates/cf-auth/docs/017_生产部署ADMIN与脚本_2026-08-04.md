## 二、脚本 `local-deploy.sh`

对齐 lottery：校验 → verify → build frontend → `--secrets-file` deploy → 生产冒烟。

```bash
bash local-deploy.sh
# 或
npm run deploy:prod

# 紧急跳过测试
VERIFY=0 bash local-deploy.sh
```

上传的 secret 名：

- `BETTER_AUTH_SECRET`、`DATABASE_URL`、`TURSO_URL`、`TURSO_TOKEN`
- `GOOGLE_*`、`GITHUB_*`
- **`ADMIN_EMAILS`、`ADMIN_API_KEY`（及可选 `ADMIN_USER_IDS`）**

## 五、与 Admin 登录事故的衔接（2026-08-04）

`local-deploy.sh` 会同步 `BETTER_AUTH_SECRET`。若该值相对库内 `jwks` 行发生变化，可能导致：

- 有 session cookie 时 `GET /api/auth/get-session` → **500**
- `GET /api/admin/health` → **401**（getSession 异常被吞）

**轮换 secret 后必须**处置 `jwks`（通常 `DELETE FROM jwks`），并用「带会话」探针验证。  
完整 runbook 与最佳实践见 **docs/018**（短）、**docs/019**（全链路）。
