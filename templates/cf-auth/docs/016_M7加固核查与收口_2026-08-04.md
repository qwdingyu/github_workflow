## 一、本轮核查发现的缺口

| 缺口 | 风险 | 处理 |
|------|------|------|
| SPA `ASSETS` 兜底 `*` | 可能抢走 `/`、`/sign-in`、`/consent` | Worker 仅托管 `/admin*`、`/assets*`；`run_worker_first` 含 `/` |
| Node `serveStatic /*` | 同上 | `server.ts` 只挂 `/admin`、`/admin/*`、`/assets/*` |
| 插件 `create-client` 开放 | 任意登录用户可发 client | `blockOpenClientRegistration`：未配 ADMIN→503；非管理员→403 |
| Admin 搜索 `like(%q%)` | `%` `_` 通配注入 | `likeContains` + `ESCAPE '\'` |
| health 不可见管理面状态 | 运维难判断是否配齐 ADMIN_* | `adminConfigured: boolean` |
| 注册脚本仍推 BA create-client | 与收口冲突 | 优先 `ADMIN_API_KEY` → `/api/admin/clients` |
| 单测未覆盖收口/503/ESCAPE | 回归易漏 | admin-api / health / search 补测 |
| prod-smoke 未覆盖 Admin/SPA | 生产路由漂移难发现 | 增 admin 401/503、home 协议页、create-client 收口 |

## 三、行为约定（运维必读）

1. **创建 client 唯一推荐路径**  
   - UI：`/admin/clients`  
   - API：`POST /api/admin/clients` + `X-Admin-Api-Key` 或白名单 session  
   - 脚本：`ADMIN_API_KEY=... node scripts/register-oauth-client.mjs ...`

2. **`POST /api/auth/oauth2/create-client`**  
   - 仅白名单管理员（或 API Key）可通过中间件  
   - 普通用户 **403**；未配置 `ADMIN_*` **503**  
   - 动态注册 `/oauth2/register` 同样收口

3. **生产 secrets**（若尚未配置）  
   ```bash
   npx wrangler secret put ADMIN_EMAILS
   npx wrangler secret put ADMIN_API_KEY
   # 可选 ADMIN_USER_IDS
   npm run deploy
   curl -s https://auth.eforge.xyz/api/health | jq .adminConfigured   # 期望 true
   ```

4. **路由优先级**  
   - Worker first：`/`、`/api/*`、`/sign-in*`、`/consent*`、`/.well-known/*`  
   - ASSETS：`/admin*`、`/assets/*`
