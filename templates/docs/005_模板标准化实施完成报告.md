## 📋 使用指南

### 创建新项目

```bash
# 选择模板
cp -r templates/<template-name> your-project-name
cd your-project-name
npm install

# 一键部署（workers 模式）
CLOUDFLARE_API_TOKEN="cfat_xxx" TURSO_API_TOKEN="turso_xxx" bash .deploy/one-click.sh

# 一键部署（pages 模式，仅 cf-static）
CLOUDFLARE_API_TOKEN="cfat_xxx" DEPLOY_MODE=pages bash .deploy/one-click.sh
```
